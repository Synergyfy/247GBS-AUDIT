# UK Business Sectors, Categories & Subcategories for Audit Platform

This document defines the full classification structure for businesses operating in the UK. It will be used on the Audit Platform to guide users through:

Sector → Category → Subcategory → Audit Questions

This structure ensures accurate targeting, relevant questioning, and precise audit outcomes.

## 15. Structure Summary for Platform Integration

Platform Selection Flow:

1. Select Sector
2. Select Category
3. Select Subcategory
4. Load Customised Audit Questions
5. Run Calculations
6. Generate Recommendations


This structure enables:
- Accurate business classification
- Relevant data capture
- Industry-specific benchmarking
- Scalable future expansion
